In `test_utf16_le_epilog_newline`, two `_XML_Parse_SINGLE_BYTES` calls passed byte counts to an `int` length parameter. The first passed `unsigned int first_chunk_bytes`, and the second passed the `size_t` expression `sizeof(text) - first_chunk_bytes - 1`. Both values are tiny and checked beforehand, so I added explicit `(int)` casts. This matches the `(int)strlen(text)` pattern used elsewhere in the expat tests. Behaviour is unchanged.
