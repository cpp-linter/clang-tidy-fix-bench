In combine_matrix, ind, ind1 and ind2 were computed as std::size_t expressions (newLen - 3, rank1 - i, rank2 - i) and then narrowed to int. For the broadcast case where a rank is smaller than i, the unsigned subtraction wraps and only became negative through the implementation-defined conversion, which the following ind1 >= 0 / ind2 >= 0 checks depend on. The sizes are now converted to int before subtracting (static_cast<int>(rank1) - i, etc.), so the arithmetic is done in signed int and yields the intended negative values portably, with no narrowing.
