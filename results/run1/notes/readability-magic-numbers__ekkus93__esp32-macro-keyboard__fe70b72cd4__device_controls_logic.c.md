The blink patterns in `device_controls_indicator_on()` used bare millisecond literals for periods and on-windows. I declared named `const uint32_t` locals at the top of the function (booting/executing/fatal period and on-time, plus the degraded pattern's 250/500/750 ms edges) and used them in the switch. The `2000U` degraded period was not flagged because it already initializes a const variable, so I left it alone. The timing is identical.
