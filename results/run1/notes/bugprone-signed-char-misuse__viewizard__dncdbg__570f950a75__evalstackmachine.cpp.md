In ImplicitCastElemType the source value (int8_t for C# sbyte) is converted to the target element type (short/int/long long). Sign extension is the intended semantics (C# implicit numeric conversion), so the suggested unsigned char cast would introduce a bug. The C-style cast was replaced by static_cast<T2>(+value1): unary plus performs the normal integral promotion (preserving the sign) before the conversion, so the value is the same for every instantiation while no longer converting a signed char variable directly to a wider integer.
