`STDIN_STAGE_MAX` was defined as `(256 * 1024)`, an `int` product. Each use in `pane_stdin_stage` (`STDIN_STAGE_MAX - p->stdin_len` and the `cap` clamp) widened it to `size_t`. I changed the macro to `((size_t)256 * 1024)` so it is a `size_t` constant from the start, which fixes all three warning sites with one change. The value is unchanged, and every use already works in `size_t`.
