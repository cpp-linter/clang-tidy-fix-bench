These four tests deliberately inspect `mapping1` after it has been moved from, to verify that MemoryMapping/TypedMemoryMapping leave a well-defined empty state. The existing NOLINT comments did not cover the hicpp alias, and adding suppressions is not allowed. Each test now binds a reference `moved_from` to `mapping1` before the move and makes its post-move checks (`REQUIRE(!moved_from)` and `moved_from.unmap()`) through that reference. The tests still check the same object and behaviour, but the intended inspection of moved-from state is now explicit, and the stale use-after-move NOLINT/cppcheck comments were removed.
