After a successful `Enqueue`, the work queue owns the raw pointer, so `item.release()` is called only to drop ownership from the `unique_ptr`. The discarded return value triggered bugprone-unused-return-value (which does not accept a `(void)` cast by default). The call now binds the result to a `[[maybe_unused]] auto* released`, making it explicit that the pointer is intentionally handed off and not leaked. Behaviour is unchanged.
